# L4 从零训练：R0–R7，20k PPO 更新

分支 `codex/l4-scratch-tradeoffs-20k`。沿用 L4 配置，从随机 actor/critic 和空优化器开始，不加载策略 checkpoint。500 次更新保存；20 秒自然验证804（低位408）、程序化验证512，以及128规整姿态负载审计。每1000及最后一次录制视频。全部相同seed 20260912，第一轮不是多seed统计结论。

|组|对照|改变|
|---|---|---|
|R0|原L4|原奖励、站起0.5秒结束，10秒上限|
|R1|R0|关闭站起结束；低SMP和数值终止规则不变，10秒上限|
|R2|R1|安静双脚站立奖励，权重+0.1|
|R3|R2|低位头部上升速度改为宽区间目标|
|R4|R2|力矩接近限幅、关节超速软惩罚，-0.05/-0.1|
|R5|R2|处理后的目标角变化惩罚，-0.005|
|R6|R2|头部接触冲击惩罚，-0.1|
|R7|R2|合并R3–R6|

R4是一个负载模块消融，不能单独区分力矩和速度的贡献。所有组安装相同的只读接触测量和质量指标；R0活动奖励、物理、actor/critic观测、reset、PPO参数与原L4核对一致。这不保证GPU仿真逐位复现历史轨迹。

## 固定训练设置

- 4096环境；actor 93D单帧、critic 960D；2ms物理步、20ms控制步；部署模型/PD/动作映射/硬力矩限幅不变。
- 固定env ID分组：后段1638、中段1642、四个低位方向各204。各方向153自然+51程序，共约15%自然低位+5%程序低位。
- LAFAN与程序化训练/验证切分不变；低位episode不因低SMP结束，其他组从第5步起保留raw SMP<0.02结束。
- f2s2 frozen prior，无GSI reset；保留actor观测噪声、固定0.3探索标准差、push和原DR。
- PPO初始学习率1e-4，自适应KL；gamma0.99等其余参数沿用L4。
- 全组20k更新；5000到10000更新，所有新增质量项线性从0到满权重。R3速度奖励也按同一个系数从旧形状插值到新形状。10000之后不自适应改权重。
- SMP运行参考从零正常估计，所有checkpoint保存其mean/count、优化器、自适应学习率与随机状态；不使用上轮缺失参考的近似重建。仍不包含完整仿真器状态，重启不是逐位连续轨迹。

## 奖励定义

原 task×SMP 奖励保留为主任务。新增成本和安静奖励在乘积之外相加。

**R3**：头高<0.9m时，满权重速度项为 `exp(-100*relu(0.10-vz)^2 -25*relu(vz-0.30)^2)`，0.10–0.30m/s为满分区间。头高>=0.9m保持原来的1。这是低位头部上升的奖励形状，不是全身速度硬上限，不要求翻身全过程单调上升。

**R4**：2ms逐子步测量实际关节力矩和速度。力矩成本为`[relu(|tau|/limit-0.7)/0.3]^2`；速度成本为`relu(|dq|/(0.5*v_ref)-1)^2`。每关节成本封顶25，每子步取最差三个关节的均值，再在10个子步上平均，减少跨29关节稀释单关节峰值的问题。参考转速来自已安装mjlab G1常量，和上轮一致；不是已实测确认的硬件安全边界。

**R5**：每20ms处理后目标角变化，`mean_j min((delta_target/0.1rad)^2,25)`。处理后指动作限幅、进入混合、PD目标投影之后。排除reset后第一步的目标不连续；保留噪声，并非对无噪声均值动作计罚。成本受探索噪声影响，需结合确定性验证判断。

**R6**：2ms头部对地净接触力，`min((relu(F-150N)/850N)^2,25) * (0.25+0.75*clip(|head_vz|/0.3,0,1))`，再子步平均。轻微静态力不惩罚，高力且头部快速运动成本更高；不是逐接触点的真实冲量。reset后前0.1秒接触惩罚线性渐入，但原始接触峰值始终记录，不用于终止。手、膝等接触没有一律处罚。

**R2**：高度、直立程度、双脚承重与脚间距平滑门控后，奖励低base/角速度、关节RMS和足端速度；对深屈膝及非脚支撑衰减。低位躺着静止不会得到站立奖励。具体尺度以提交中的`cache_control`及校准记录为准，正式开始后固定。

## 日志和评测

- `Tradeoff/{all,low,supine,prone,left,right}`：原始成本、子步峰值和quiet_score。`full_cost_to_task`是不乘渐入系数的成本/任务奖励比，低位任务奖励接近零时可非常大，不能把比值本身当安全指标。
- `Recovery/.../stable_step_fraction`和`hold_seconds`记录站稳过程。R1–R7关闭站起结束，因此`Episode_Termination/stood_up`或旧`Quota/stood_fraction`为0是协议结果，不能用它判断没学会。
- `Validation`/`ProceduralValidation`统一20秒、严格连续站稳10秒。自然低位408中340仰卧，必须同时看分方向与程序化均衡验证。
- 每500额外128规整初态负载评测，输出每关节峰值、RMS、接近力矩限幅和超过参考转速阈值的时间占比，以及头部净力。`LoadValidation`为这些独立评测结果，和训练噪声分布分开。
- 各run保存initial.pt、初始姿态/网络hash、实际配置、完整训练checkpoint。选checkpoint依赖验证；最终保留独立test作一次终评。禁止用测试集反复调权重。

## 启动验证

先单独用冻结L4进行512环境、500控制步的成本探测，输出仅作奖励量级检查，绝不用于初始化正式网络。随后八组各4096环境、4次PPO更新，检查同初始网络/姿态、无checkpoint加载、各配置差异、SMP参考保存与三个评测流程。短跑时质量渐入系数为0，因此它验证初始化/运行流程而不证明满权重训练效果；满权重成本可达性由另一次冻结策略探测和数值检查提供证据。


校准记录：第一次严格指数quiet形状，在噪声下平均仅3.5e-5，已改为分母递增的平滑形状。最终为门控×膝姿态项 / `[1+(base/.25)^2+(angular/.5)^2+(joint_RMS/2)^2+(foot_max/.2)^2]` / `[1+非足承重/80]`。第二次逐控制步探测，安静分数平均0.080、3秒后0.095；R7总惩罚约为任务奖励的9.4%，起身最初1秒约101%。这些是冻结已学会策略下的探测，不代表随机初始策略的成本分布。因此质量项固定在5k–10k渐入，给基础恢复留出学习时间。头部成本峰值6.096，权重最终取-0.1；它不用于终止。所有数值在正式启动前确定，未来变化须另建实验。
