# F0–F4：从同一个 R1 出发验证姿态、持续负载和末段减速

本轮是五组 **finetune 消融**，不是新的 from-scratch 结果。先验证约束是否有效，之后再决定 from-scratch 课程；本轮没有启动 S0–S3 或地形实验。

## 共同设置

- 分支 `codex/r1-staged-quality-finetune`。
- 源模型 `logs/rsl_rl/scratch_tradeoffs/formal_20260914_234350/R1/model_19999.pt`，SHA256 `173cf5af73c28e3839ba4d37e5069488ca61368fac1abba878066948f73d9d98`。
- 恢复 actor、critic、两者观测归一化、optimizer、学习率，以及 checkpoint 保存的 SMP mean/count。源学习率为 2.25e-5，继续原 adaptive KL 调整。保留源策略的动作分布参数，不把探索std重置。
- 4096环境；每组追加5000次更新，编号20000–24999；新增reward在前500次更新从0线性增加到全权重。相同seed和初始qpos/actor/critic/SMP状态哈希已在五组preflight核对。
- 每500更新保存和评测，保留初始checkpoint；跳过更新20000的重复评测，首次周期评测20500，最后24999。每1000及末次录制20秒视频。
- 训练episode仍为10s，取消站起终止；低位20%环境不因低SMP结束，中/后段保留原低SMP阈值0.02与5步宽限，数值异常和超时仍结束。
- 93D单帧actor，960D critic；actor观测噪声、动作探索、push、摩擦、编码器偏置、躯干COM随机化全部保留。不改模型、PD、动作投影、硬力矩限值、prior、task-SMP乘积。
- reset固定配额：后段1638、中段1642、低位四方向各204；每个低位方向153 LAFAN＋51程序化。全体约40%后段、40%中段、15%自然低位、5%程序化低位。不使用GSI生成reset。
- 新鲜的成对reset episode；源checkpoint不包含仿真接触状态和事件计时器，因此不是逐位续跑源轨迹。没有重建SMP参考值。

## 新reward的定义

平滑函数 s(x;a,b) 使用0–1 smoothstep。接近站立门控为 `g=s(head_height;1.0,1.15)*s(upright;0.8,0.93)`。不增加终止条件。

### F1：自然站姿

软参考使用部署默认上肢姿态，腿部改为双侧 hip_pitch=-0.15、knee=0.30、ankle_pitch=-0.15 rad，其余参考关节不变。肩pitch=0.2、肩roll=±0.2、肘=0.6，腕及腰为0。它是可检查的工程参考，并非已有硬件验证过的站姿。

按肩0.35、肘0.40、腰0.20、其余关节0.25 rad归一化关节误差，再将上肢均方误差＋腰均方误差＋0.5×下肢均方误差相加。加躯干倾斜误差 `sum((projected_gravity_xy/0.15)^2)`。

自然站姿得分为 `g * support / (1+pose_error+tilt_error) / (1+nonfoot_load/80)`。support要求双脚载荷从5N到20N平滑增加，足间距下界0.08–0.12m、上界0.45–0.55m平滑过渡。不对翻身强制对称，不直接要求全程跟踪该关节向量。

几何检查：头高约1.261m、足间距0.237m、关节在限位内，无明显碰撞穿透；这只验证几何可行，不代表动态或硬件安全。

### F2：持续力矩

每2ms对每关节 `(tau/tau_limit)^2` 做零初值、时间常数0.5s的指数平均，开方作为归一化RMS代理。代价为 `mean(top3((relu(rms-0.45)/0.55)^2))`，并在每个环境reset时单独清空历史。

允许短促载荷，持续高负载逐渐增加代价；全阶段生效，不能通过不站起逃避该项。0.45是本轮实验阈值，不是厂商连续力矩限值；0.5s是负载滤波时间常数，和低SMP终止宽限无关。

### F3：末段速度与目标变化

速度项每2ms计算 `relu(abs(dq)/(0.2*v_ref)-1)^2`、上限25，取最重3个关节均值，再平均10个子步并乘g。v_ref延用原实验工程速度参考，因此阈值按关节约4–7.4rad/s，软惩罚而非硬截断。

目标变化为实际处理后目标角相邻20ms变化除以0.1rad后的平方，逐关节上限25，取均值并乘g。每次reset后的首步不计入该项。观测噪声和动作探索保留，因此这个代价也会受到探索噪声影响；不把目标变化解释为实际关节速度。

原始向上运动reward完全保留，避免R3静止低位收益大幅增加的问题。

## 校准与评测

冻结R1的512环境500步随机动作回放（实际策略分布、噪声、DR和push开启），没有PPO更新：全阶段平均task约0.480，F2全权重惩罚/task约2.04%、F3约1.86%、F4约1.95%；低位对应约2.09%、1.90%、1.99%。自然姿态原始得分约0.257，非零信号。校准仅确认量级，不保证学习改善。

五组4096环境各4次PPO预检，并通过自然验证、程序化验证、128固定姿态负载检查后才正式启动。正式均从原R1重新恢复，不沿用预检或probe训练结果。

周期验证：自然银行804姿态（其中低位408），程序化512姿态，统一20s、连续严格站立10s。128固定姿态负载按2ms记录全程和前5s峰值、关节RMS、超阈值占比、头部净接触力，并增加接近直立阶段姿态误差、归一化力矩RMS和高力矩占比。该负载评测接近直立定义为head>=1.15m且upright>=0.93，不能等同于已经安静站稳。

评测使用标称动力学和确定性actor，训练扰动不因此关闭。只有通过本轮恢复和质量筛选的候选，才进一步做带扰动评测、部署端sim2sim和独立测试集。某策略没有进入直立阶段时，相关统计可能为0，必须结合直立有效样本比例和成功率解读，不能把失败当作低负载。
