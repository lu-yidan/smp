# 固定低桌专项微调：T0 / T1 / T2

分支：`codex/a6-table-specialist`。本文中的 T0/T1/T2 属于本轮 **table specialist**，不要与历史多地形 T 系列混用。服务器工作目录 `/mnt/workspace/user/luyidan/smp-table-specialist`。

## 问题与对照

从真机验证过的 `A6_no_alpha@9999` 出发，学习从固定、有四条腿的低桌下爬出，再完成恢复。桌子完全固定，不能靠顶翻或抬起完成任务。本轮不训练自由板、升降板和台阶。

| 实验 | 相同基础 | 唯一新增内容 |
|---|---|---|
| T0 | A6_no_alpha 的 task×SMP、几何引导、Q/L、执行代价 | 适配固定桌场景与 reset；保留历史奖励结构 |
| T1 | T0 | 脱困还需离开四条桌腿至少 2.5 cm；确认脱困后关闭几何进展、稠密 clearance、向外分离进展奖励 |
| T2 | T1 | 脱困后的位移软约束，以及较轻的站姿／脚速／身体速度收敛项 |

T2 位移以**首次确认脱困时的位置**为锚点，不以桌下初始位置为锚点。25 cm 内不罚；超出部分用平方代价（尺度30 cm，最大10），权重 −0.08，并受近站立门控。站姿、脚速、身体速度项权重分别 +0.04、−0.01、−0.01，继承 R2 的站立、双脚支撑与非受困门控。这些是待验证的干预，不预先承诺一定改善。

共同适配：初始受困资格来自通过筛选且躯干在桌面投影下的 reset，不要求先撞击桌面才获得引导奖励。桌面和每条桌腿均监测接触；力惩罚取各部件监测的最大力。这也是与原版压板实验的场景差异。

## 场景与 reset

尺寸均为完整长度；高度是**地面到桌板下表面的净空**，不含板厚。

| 类别 | 环境比例 | 长×宽（m） |
|---|---:|---|
| 方桌／近方桌 | 35% | 长0.85–1.25；宽=长×[0.9,1.1]，截断到0.80–1.25 |
| 长桌 | 40% | 长1.10–1.70；宽0.55–0.85；长宽比1.5–2.8 |
| 长椅 | 25% | 长1.00–1.40；宽0.35–0.50 |

每类内仰卧／伏卧各50%；每种朝向中自然 LAFAN 低位75%、程序化低位25%。4096环境按可整除的数量近似该比例；准确计数见运行的 `reset_audit.json`。姿态有随机全局 yaw，桌子中心相对骨盆或胸部随机偏移。它不是所有朝向、位置都能被接受的无条件均匀分布：穿模、无躯干覆盖及关节越界样本被拒绝。

板厚3–6 cm；桌腿截面4–7 cm；桌腿内缩0–4 cm；桌子摩擦0.8–1.4。先只训净空35–40 cm。每1000更新验证一次，若较高净空六个类别×姿态的平均诊断 SR3≥60%，且各组≥40%，加入10%较低净空（30–35 cm），最多30%。本轮不含20–25 cm，也不含60×40 cm的小桌。

训练池6144、验证池1536，均含两个净空档和所有类别／姿态／来源。实际训练按上述课程取样。源姿态索引按80/20划分，训练验证索引不重叠，但**不代表动作片段不重叠**。几何尺寸、位置、摩擦预先连续采样后储存在有限池中，reset 随机重采样池中的整行。

筛选：使用部署机器人碰撞几何；地面最低碰撞边界3 mm；关节限位和胸部朝向检查；MuJoCo 初始自碰撞／地面穿透不超过1 mm；所有机器人碰撞几何 AABB 与五个桌子盒体的分离间隙≥3 mm。这一筛选偏保守。它只保证初始状态合理，不能保证该状态一定可以恢复。

## 追加：脱困后位移消融 T3–T5

用户希望离开桌子后尽量不继续移动。本轮新增三组仍从相同 A6_no_alpha 父策略开始，不从已训练的 T2 接着微调。reset 池、随机化、种子、4096环境、10k预算、500保存均相同。

| 组别 | 位移惩罚权重 | 生效门控 | 额外站立收敛 |
|---|---:|---|---|
| T1 | 0 | 无 | 无 |
| T2（已有） | −0.08 | 近站立高度／直立度门控 | 有 |
| T3 | −0.08 | 与T2相同 | 无 |
| T4 | −0.08 | 首次脱困后0.5 s线性增至全强度，不依赖高度 | 无 |
| T5 | −0.24 | 与T4相同 | 无 |

对照关系：T1/T3测试位移项；T3/T2测试额外站立项；T3/T4测试激活是否太晚；T4/T5测试强度。

令 `d=||base_xy−escape_anchor_xy||`，共同代价为 `min(10, (max(d−0.25,0)/0.30)^2)`。锚点在确认脱困时记录并保持，只有 episode reset 才重置。T4/T5 的激活系数为 `clip(time_since_escape/0.5,0,1)`。不惩罚竖直上升，不要求回到桌下原位置。25 cm 是免费区域而非硬上限；大权重可能使策略停在低位，必须联合成功率评估。

每组课程采用同一门槛规则，但由自身验证表现触发，低净空占比可能随训练产生差别。因此课程分化后的结果是完整训练方案的对照，不能声称全程看到了完全相同的训练分布。最终使用相同验证池、类别比例、姿态与净空分层比较。

验证新增：
- `drift_escaped_p95`：只对已脱困episode统计其观察窗内的最大位移P95；未脱困者不以零位移混入。
- `drift3_p95`：首次脱困后3 s内最大水平偏移的P95，只纳入有完整3 s观察的样本。
- 同时报告 `n_escaped`、`n_post3`、SR3及脱困比例。窗口不足的样本不补零，也不能把低位停滞当作收敛。
- 现有 `drift_p95` 保留兼容，但它混合未脱困样本，不用于单独判断位移改进。

代码边界检查：`scripts/check_table_drift_contract.py` 验证脱困前零代价、25 cm免费区、低姿态也能启用新代价、0.5 s渐进，以及组间未改其他reward。T3/T4/T5还各跑128环境5 s rollout与2次PPO更新。
