# 低桌下先爬出、再起身：CR0–CR5

分支：`codex/a6-crawl-first`，基于 `92f8b1c`。服务器 `dsw1-clone`，工作区 `/mnt/workspace/user/luyidan/smp-crawl-first`。

目标是修复先坐起、俯身顶桌的动作偏好，同时保留脱离后的起身能力与位移约束。本轮不是泛化论文结论，也不是 alpha 数值扫描；先用共同 seed 对机制进行筛选。

所有组从 actor、actor normalizer、动作标准差完整迁移；critic 与 optimizer 重新初始化。CR0沿用T4奖励，但用新的初态分布和所有组统一的全身投影脱离判据，因此并非历史T4结果的逐位复现。

## 桌子与 reset

- 板下净空统一 **0.32–0.40 m**，分8个1cm区间采样。高度指地面到桌板下表面的距离，不包含厚度。
- 每个组合先固定高度、尺寸，再寻找接触有效姿态；不因姿态难放而重新抽高桌子。运行时从有限预生成库采样。
- 正方桌35%：长0.85–1.25m，宽为长的0.9–1.1倍并裁剪到0.80–1.25m。
- 长方桌40%：长1.10–1.70m、宽0.55–0.85m，长宽比1.5–2.8。
- 长椅25%：长1.00–1.40m、宽0.35–0.50m。
- 板厚3–6cm，腿宽4–7cm，腿内缩0–4cm，桌面摩擦系数0.8–1.4；均为固定四腿桌。
- 仰卧/伏卧各50%；自然LAFAN低位/程序化低位各50%。程序化姿态重新生成，非旧坐起姿态强行压低。四个桌边的初态布置方向均匀；**不强制指定机器人从哪一边出去**。
- 深处：骨盆/胸部中心至所选边的内侧距离为该轴半长的35%–80%；近边：1–6cm；桌外：全身投影离桌面至少4cm。
- 候选姿态经0.6s名义PD沉降，筛掉明显穿插或未稳定状态，再以零初速度重置。机器人与桌子各碰撞体的AABB间距至少3mm，CPU接触允许数值级约1mm误差。
- 训练库9,216条、验证库4,608条；自然姿态源索引不交叉，程序化随机种子不交叉。这不是按原始motion clip隔离的泛化测试。
- 首轮不自动降低桌高。是否扩展至28–35cm需先看共同验证结果与动作视频。

## 起身与爬行的切换

CR1–CR5受困时将 `stage_pose / head_velocity / height / upright` 四项乘以0，并冻结起身阶段为第0阶段；SMP、其余五项task、Q/L、执行代价以及脱困几何奖励保留。不是将整个task乘以某个alpha，也不把移除项补成常数奖励。

脱离要求所有机器人碰撞体的XY投影离开桌面投影至少2.5cm、与桌板/桌腿的3D AABB分离至少2.5cm且无接触，持续0.3s。随后0.5s线性恢复起身四项；重新进入投影后立即回到爬行模式。首次脱离位置只记录一次，几何进展的历史最好值不清零，避免重复进出刷进展。

局部净空代价：仅对仍被桌面覆盖的头、胸、骨盆碰撞体，惩罚其上沿超过“桌底−2cm”的部分，按5cm归一化、平方、上限4，取这些碰撞体的最大值，权重−0.10。

温和接触代价：保留原有300N阈值的接触代价，另将桌面传感器的最大接触力模长超过85N的部分除170N、平方、上限25，在物理子步平均，权重−0.05。85N是本次待验证的优化尺度，不是硬件安全认证阈值；该传感器采用接触归约，**并非所有接触点法向力之和**。此项不作用于地面支撑力。

所有组保留T4的脱困后位置代价：首次脱离点为锚，25cm自由半径、30cm归一化尺度、平方上限10、权重−0.08，脱离后0.5s渐入。首次脱离后关闭几何进展、稠密clearance、向外分离进展奖励；不是强制回到最初躺地位置。

## 训练、随机化与验证

- 每组4,096环境，10,000 PPO更新，保存间隔500，共同seed20261008，学习率1e−5，episode20s。
- Actor93D及观测噪声保留；SMP f2s2及冻结分数归一化参考保持不变。
- 无低SMP终止、无站起终止；只保留超时/仿真不稳定终止。
- 动力学沿用历史实现：25%名义动力学、75%随机化；腿/上身/骨盆组质量和惯量同比例缩放，电机分组Kp/Kd同比例缩放，范围前2k更新由±10%扩到±20%；命令延迟0、2、4、6、8、10ms；保留push事件。
- 每1,000更新共同验证768次，名义动力学、无push，随机桌型、尺寸、初态相同。训练随机化鲁棒性还需独立stress评测，不能由这一验证直接推断。
- SR3：20s内开始站立，连续确认3s，观察至23s；头高≥1.15m、基座uprightness≥0.90、双脚各>20N。不要求完全静止。
- 单列桌下deep、near和桌外组；`table_only`排除本就桌外的10%，避免用直接起身抬高脱困成绩。仿真不稳定记失败，不做事后无效样本筛除。
- 除SR3/脱离率，记录脱离后3s最大位移P95、物理子步关节扭矩/速度/功率峰值P95、连续高负载时间P95和桌面接触峰值。
- 本轮选择重点：动作是否先低位通过、伏卧是否改善、接触负载是否下降、脱离后是否继续大幅走动；不能只按总SR3选赢家。
