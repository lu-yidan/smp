# V33 / V34：保留速度观测的30 cm固定桌视频

用途：观察历史脱困策略能否在当前固定四腿桌下先低姿移动、再起身。不是旧压板任务成功率的复现。

- V33：原始 `model_95000.pt`。
- V34：原始 `model_98000.pt`，不是后来的93D gate6000版本。
- 原始96D actor与观测归一化完整载入；前三维实际读取 `robot/imu_lin_vel`，每步核对，未置零。角速度、关节速度等也保留。
- 使用共同的当前部署机器人模型、PD、入场混合和力矩投影，不能把结果等同于历史训练动力学。
- 复用30 cm独立碰撞筛选库，种子20261071，256环境；两策略使用同一批初始状态。
- 只录制方桌仰卧与伏卧，每个方向选第一个匹配状态，不按成败挑选。桌板下表面净空0.30 m，具体长宽写在视频里。
- 每段23秒、25fps、原速，低视角。SR3为20秒内开始连续站立3秒。爬行风格需要看动作，不能以SR3代替。
- 录制脚本：`scripts/record_legacy_crawl30.py`。
- 服务器：`dsw1-clone:/mnt/workspace/user/luyidan/smp-crawl-repair/logs/legacy_crawl30`。
- 当前CF0/CF1/CF2训练不变。

## 结果

两策略 initial.npz 全部字段逐项完全一致，速度输入检查通过，最大绝对速度观测分别1.914、1.407 m/s（全批环境）。

录像中的两个状态均为deep起点。V33与V34在仰卧、伏卧这四段均未完成脱困/恢复。桌面长宽分别约1.18×1.22 m（仰卧）、1.04×1.04 m（伏卧）。256环境中的228个桌下状态，SR3为V33 0/228，V34 6/228；仅代表当前部署动力学、固定桌与该reset库，不否定历史小型升降压板中的表现。
