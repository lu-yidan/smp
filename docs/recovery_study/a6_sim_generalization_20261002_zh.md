## 证据边界与判据

- 杂物留出组相对旧杂物development分离，共94个不同源机器人姿态，多个布局复用姿态；**不保证与全部历史训练姿态独立**。它检验障碍组合泛化，不是480个全新独立姿态或多seed训练。
- **Q10**：20s内连续10s满足安静站立条件。条件沿用既有杂物协议：支撑相对头高、直立度、双脚载荷、脚/基座/关节速度、膝角、脚宽、非脚承托和支撑运动。
- **E10**：Q10且直接刚体竖直抬升碰撞探针持续畅通。探针逐个真实碰撞分件检测、保留箱体/梯子的空洞；它是保守几何诊断，**不是所有关节运动的可达性证明**。同时报告Q10，区分站稳但残留障碍与未能站稳。
- E1/Q1同理。完全脱困与稳定站立分开，不将箱子挂在手臂上的站立自动当作完全脱困。
- 本轮E10与训练仿真板phase判据不同，不直接混合两个成功率。
- 脱离/站稳后3s最大XY位移仅纳入完整观察窗并报告分母。力矩、关节速度、机械功率按500Hz记录，先取每次试验的最大值，再跨试验取P95；不等同电功率或硬件安全限值。
- Wilson区间仅作这些试验的描述统计，不表示独立训练seed的不确定性。

## 板参数敏感性结果

896例全部完成，另4例平地校准4/4。每个格子64例，记Q10 / E10；与上面的杂物试验同一控制与判据。

|参数条件|上下导向板 Q10 / E10|自由板 Q10 / E10|
|---|---:|---:|
|基准|53/64（82.8%） / 53/64（82.8%）|61/64（95.3%） / 57/64（89.1%）|
|长宽×0.75|55/64（85.9%） / 55/64（85.9%）|59/64（92.2%） / 59/64（92.2%）|
|长宽×1.25|49/64（76.6%） / 49/64（76.6%）|60/64（93.8%） / 44/64（68.8%）|
|质量3kg|42/64（65.6%） / 42/64（65.6%）|64/64（100.0%） / 56/64（87.5%）|
|质量9kg|58/64（90.6%） / 58/64（90.6%）|58/64（90.6%） / 52/64（81.2%）|
|板—机器人摩擦0.5|55/64（85.9%） / 52/64（81.2%）|62/64（96.9%） / 57/64（89.1%）|
|板—机器人摩擦1.5|59/64（92.2%） / 59/64（92.2%）|59/64（92.2%） / 51/64（79.7%）|

自由板Q10为90.6%–100%，上下导向板为65.6%–92.2%；轻导向板并没有比重板更容易，显示接触/支撑策略的效果并非质量单调函数。该解释仍需对应轨迹，不据64例宣布普遍规律。长宽增大的自由板Q10仍为60/64，但E10为44/64，提示站立与完全清除周围障碍是不同目标。

**探针语义复核：**杂物中34例Q10成立而E10不成立（可移动场景33例，固定场景1例）。在各自最长安静站立段的末帧，12例探针只与脚部发生碰撞，3例只与手、14例其它身体部位、3例混合，另2例该帧已不再受阻但没有累计到E10。脚边木条、箱沿会使刚体整体抬升失败，不能由此证明机器人仍无法通过调整关节脱困。因此原E10完整保留，作为严格诊断；论文主文应把连续站稳与残留物诊断明确分列，不把E10简单叫“起身成功率”。
